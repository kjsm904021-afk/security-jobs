# 보안·경비 최신 채용보드 v2 — 자동갱신형

이 버전은 같은 웹주소를 열 때마다 최신 `data/jobs.json`을 읽고, GitHub Actions가 3시간마다 공개 채용페이지를 확인해 목록을 갱신하도록 만든 버전입니다.

## 핵심
- 같은 사이트 주소 유지
- 3시간마다 자동 갱신
- API 키 필요 없음
- IT/사이버보안 제외
- 보안대원, 경비, 특수경비, 공항보안, 보안검색, CCTV관제, 출입통제, 경호, 청원경찰 등 포함
- 가정역 / 루원시티 루에블리 / 독정역 생활권 기준으로 통근등급을 1차 분류

## 한 번만 설정하면 됨
1. GitHub에서 새 저장소를 만듭니다. 예: `security-jobs`
2. 이 ZIP 안의 파일을 저장소 루트에 업로드합니다.
3. 저장소 → Settings → Pages
4. Source: `Deploy from a branch`
5. Branch: `main`, Folder: `/ (root)` → Save
6. 저장소 → Actions → `Update security jobs` → `Run workflow` 한 번 실행
7. 이후 자동으로 3시간마다 갱신됩니다.

사이트 주소 예시:
`https://내아이디.github.io/security-jobs/`

## 중요한 제한
API 키 없이 각 사이트의 공개 검색/공고 페이지만 읽습니다. 사이트가 자동접속을 막거나 HTML 구조를 바꾸면 해당 출처는 일시적으로 갱신되지 않을 수 있습니다. 캡차나 차단을 우회하지 않습니다.

또한 API 키 없이 정확한 대중교통 길찾기 시간을 계산할 수 없으므로 ◎/○/△는 지역 기반 1차 분류입니다. 교대근무의 첫차/막차는 원문 확인이 필요합니다.


## v2.1 배포 방식
GitHub Pages의 Source는 **GitHub Actions**로 선택하세요.
이 버전은 3시간마다 공고를 갱신한 뒤 같은 워크플로에서 사이트까지 직접 다시 배포합니다.
`Deploy from a branch`는 사용하지 않는 것이 좋습니다.
